# Story assets

The FoundPhone-Studio template story references these image files:

- `p1.jpg` — lock-screen wallpaper
- `p2.jpg` — home-screen wallpaper
- `p3.jpg` — KakaoTalk contact avatar for `리쿠`

Place the three supplied photos here using these exact filenames. The story JSON points the contact avatar at `./story-assets/p3.jpg`; the phone runtime loads the wallpapers from `/story-assets/p1.jpg` and `/story-assets/p2.jpg`.
